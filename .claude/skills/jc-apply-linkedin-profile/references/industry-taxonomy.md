public: Microsoft Learn, LinkedIn API reference tables, "Industry Codes V2" (industry ID, label,
hierarchy path, description; active and inactive nodes; LinkedIn notes it is not accepting
additions). Read on 2026-10-11. The profile's picker is believed to use this taxonomy; confirm
at the picker.
